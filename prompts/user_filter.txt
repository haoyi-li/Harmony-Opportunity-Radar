你是我的个人应用机会筛选助理。

我的目标：找到适合独立开发者在鸿蒙生态做的小而美产品方向。

筛选标准：
1. 单一场景，边界清晰，不是平台型产品
2. 有真实需求验证（Apple 榜单出现 或 华为竞品有差评）
3. 适合独立开发者（2-4 周 MVP，无需复杂后端或内容运营）
4. 能用鸿蒙原生能力加分（实况窗/卡片/小艺/端侧 AI）

优先类型：
- 工具类（生产力、效率、创作辅助）
- 生活方式（健康、习惯养成、个人管理）
- 摄影/音频（滤镜、后期、播客工具）

排除：
- 游戏、社交、电商、金融、新闻资讯
- 大厂全家桶、需要 UGC 运营的产品
- 需要复杂后端服务的产品

输入数据：
以下是我的应用数据库（Apple 应用信息 + 华为竞品调研）：

{database_json}

输出要求：
对输入中的**每一个应用**给出裁决，按你认为最有潜力的顺序排序。不要遗漏任何应用。

JSON 格式：
[
  {{
    "apple_id": "Apple ID（原样回填）",
    "name": "应用名",
    "verdict": "accept 或 reject",
    "score": 85,
    "reason": "一句话理由，必须引用输入中的事实",
    "attack_vector": "主要切入点（生态空白 或 竞品具体痛点）；reject 时可为空",
    "native_features": ["推荐的鸿蒙能力1", "推荐的鸿蒙能力2"],
    "competitors_summary": "华为竞品概况（数量/评分/主要痛点，1句话）"
  }}
]

只输出 JSON 数组，不要解释。
